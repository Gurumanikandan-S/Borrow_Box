# BorrowBox Web Prototype

BorrowBox is a campus-focused peer-to-peer platform where **every user can be both a lender and a borrower**.

## MVP included
- Explore available items
- Search and category filter
- User profile
- Post your own item
- Free or paid borrowing
- Refundable deposit concept
- Borrow request simulation
- My Items dashboard
- Requests page
- Trust score
- LocalStorage persistence

## Run
Open `index.html` in any modern browser.
